# 实施路线与验收状态

- [x] 固定 SDK、依赖锁、CI、许可与复用记录
- [x] USB 扫描、权限、端口选择、连接、读写、故障和清理
- [x] connectedDevice 前台服务、会话快照、CPU 唤醒锁

- [x] 原生四页 UI、图像/SVG 文件选择、参数、预览、导出
- [x] 图像裁剪/旋转/灰度/Gamma/阈值/反色/抖动/扫描

- [x] 星光独立模块与手动设备 JSON 配置导入
