# 0.3 可安装演示版

## 下载与安装

打开 [GitHub Actions](https://github.com/DGHH-Skywalker/GRBL_Tool_mobile/actions)，选择成功的 Build and test 运行，在 Artifacts 下载 `android-apk`，解压后安装 `*-Signed.apk`。系统要求 Android 10（API 29）及以上。`SHA256SUMS.txt` 提供 APK 文件校验值。

本版同时包含 USB 控制与离线演示。全部业务逻辑运行在手机内；演示无需网络、USB 或额外硬件。版本名 0.3.0，应用 ID 为 `io.github.dghhskywalker.grbltoolmobile`。

## 三分钟体验

1. 在设备页点击“体验完整演示”。应用创建内置 GRBL 会话，读取配置并进入就绪，生成 100 多行蛇形演示任务。
2. 作品页查看路径，单指平移，双指缩放。“适合屏幕”恢复视图。
3. 进入加工页，查看任务名称、估时、哈希和功率提示，勾选确认后点击“开始加工”，确认任务摘要。
4. 点击暂停，观察状态由 Pausing 进入 Paused；继续时再次确认。
5. 加工期间按 Home 返回桌面，通知显示进度并提供暂停入口。再次打开应用查看当前任务；等待 Completed 后进入历史页查看名称、哈希对应记录、启动坐标及确认行数。
6. 作品页修改尺寸或参数，开始按钮随即失效；重新生成任务后重新确认。
7. 使用系统文件选择器导入自己的 G-code、PNG/JPG/SVG。`samples/demo.svg` 与 `samples/dry-run.nc` 可用于导入体验。

演示使用独立的软件传输器、180 ms 的模拟执行时钟和虚拟坐标。ACK、控制器执行与完成屏障分别发生。演示耗时用于交互体验；界面估时根据 G-code 进给计算。

## 故障体验

设备页提供“演示：设备报警”“演示：控制器复位”“演示：连接中断”。

- 任务中发生报警：执行进入 Interrupted，开始加工禁用。结束故障原因后点击软件复位，等待 Idle，读取配置并确认设备就绪，按新任务重新启动。
- 控制器复位：控制器世代递增，当前任务进入 Interrupted；读取新配置并人工就绪后创建新执行。
- 连接中断：会话标记 Lost，历史保留 Interrupted。点击断开连接，再次进入演示模式。
- 应用进程被系统终止：下次启动将未完成执行标记为 Interrupted，重新连接后创建新执行。

暂停保留当前任务；复位与中断结束当前执行。启动命令持久化去重，重复命令 ID 返回原结果，不重新发送加工内容。

## USB 实际工作流

1. 退出演示连接，使用 OTG 连接控制板。
2. 扫描并选择端口，核对波特率后授权连接。
3. 设置工作区域和速度/功率上限，读取固件与配置。
4. 根据实际位置点动、设置工件原点，等待最新 WPos；点击“确认设备就绪”。
5. 导入作品并生成、查看预览，再在加工页确认并启动。

本版以标准 GRBL 1.1 的 XY 方言工作。启动按实时 WPos 重新校验整个路径。G0/G1、G20/G21、G90/G91、G54/G17/G94、M3/M4/M5、X/Y/F/S 已实现；首个移动前声明单位、距离、运动模式及 M5。支持列表之外的指令在导入时给出错误。

具备 `[OPT:...,planner,rx]` 报告时，使用小于 RX 容量的字符窗口；其余设备使用逐行确认。确认行数表示解析确认；Completed 来自所有任务 ACK、G4 P0 ACK 和屏障后的新 Idle 状态。

## 构建与签名

GitHub Actions 完成锁定依赖恢复、核心测试、原生 Skia 测试、Release APK 构建、签名检查、SHA256 和 Android API 35 模拟器交互检查。模拟器证据存入 `demo-smoke-evidence`，包含截图、UI XML、结果及 logcat。

演示签名密钥和随机密码保存在 Actions cache，源码仓库不保存密钥。cache 保留期间的构建可覆盖安装；缓存失效后生成新演示身份，旧安装需先卸载。正式渠道发布使用持久备份的发布 keystore，并通过 GitHub Secrets 注入签名配置。
