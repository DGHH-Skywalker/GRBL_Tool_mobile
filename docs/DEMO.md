# 0.4 单屏移动演示版

## 下载与安装

安装包和镜像地址见 [DOWNLOADS.md](DOWNLOADS.md)。Android 10（API 29）及以上，ARM64 或 x86_64，下载 APK 后直接安装。

本版采用底部四栏导航、页内分类和分步表单。主页面固定显示，参数和历史通过按钮翻页，界面设计依据及文件白名单见 [MOBILE_UI.md](MOBILE_UI.md)。

## 完整演示

1. 设备页的“连接”分类点击“体验完整演示”。应用创建内置 GRBL 会话、读取配置并生成演示任务。
2. 作品页的“预览”分类查看路径，单指平移、双指缩放，使用“适合屏幕”恢复视图。
3. 点击底部“加工”或作品页“去加工”。核对摘要与路径、勾选确认，点击开始，再确认实际起点和范围。
4. 暂停、继续和取消始终在加工页下方显示。暂停等待设备 Hold:0，继续需再次确认。
5. 加工时按 Home 回到桌面，通知显示进度并提供暂停入口。返回应用可查看任务完成。
6. 历史页在“任务库”“执行记录”间切换，用上一页和下一页浏览。选择任务恢复预览，执行详情与日志也采用短页阅读。
7. 作品页修改参数会使已生成任务失效；重新生成后才能重新确认开始。

演示使用虚拟坐标和 180 ms 执行时钟。手机内的 DemoTransport、DeviceSession、任务、暂停、完成确认与持久化使用同一业务链路。ACK、规划队列执行和完成屏障分别发生。

## 导入作品

点击“导入作品”，选择位图、SVG 或 G-code 类别，再从系统文件选择器选择文件。

- 位图：PNG、JPG/JPEG、WebP、BMP，最大 16 MB，最多 1200 万像素，静态且可完整解码。
- SVG：最大 2 MB，遵守已支持的 SVG 结构与外部资源限制。
- G-code：NC、GCODE、GC、NGC、TAP、CNC，最大 4 MB，ASCII 文本，支持 UTF-8 BOM。
- 设备 JSON 仅从设备页的“参数”分类最后一步导入。

导入时核对扩展名、提供者 MIME、文件大小及实际内容；检查失败保留原作品。PDF、GIF、ZIP、EXE、无关 TXT 和改后缀伪装的文件会被拒绝。

加工参数按“尺寸与精度”“速度与功率”“图像算法”分步填写。图像调整按裁剪起点、裁剪终点和旋转分步填写。每一步通过上一步、下一步切换，输入时系统键盘占用空间由布局自动预留。

位图与 SVG 使用这些图像参数；G-code 沿用文件内的 F/S。导入后点击“生成任务”，查看预览，再去加工。

## USB 工作流

1. 在设备“连接”页退出演示，OTG 连接原控制板，扫描并选择串口后授权连接。
2. 设备“参数”页填写工作区域、速度/功率上限和串口波特率；回到连接页读取配置。
3. 设备“定位”页点动并设置工件零点，等待最新 WPos 后确认就绪。
4. 导入、生成并查看作品，在加工页核对实际起点和范围后开始。

标准 GRBL 1.1 的 XY 方言支持 G0/G1、G20/G21、G90/G91、G54/G17/G94、M3/M4/M5、X/Y/F/S。首次移动前需要单位、距离、运动模态及 M5 初始化。G-code 在导入、准备与启动时按相应约束校验。

报告 RX 容量时使用字符窗口，未知容量使用逐行确认。Completed 来自任务 ACK、G4 P0 ACK 及屏障后的新 Idle。确认行数表示解析确认。

## 故障体验

设备“维护”分类第二步提供模拟报警、模拟复位和模拟断线。

- 报警后当前任务进入 Interrupted。处理原因后软件复位、读取配置并确认就绪，创建新执行。
- 控制器复位使世代递增，旧任务结束；读取配置并人工就绪后再开始。
- 断线使会话变为 Lost；断开后重新进入演示或重新连接。
- 进程重启将未完成执行保留为 Interrupted。启动去重、复位和恢复规则保持原有实现。

## 构建、签名与验收

GitHub Actions 执行核心与原生 Skia 测试、Release APK 构建、签名检查、SHA256 和 Android 模拟器交互检查。模拟器脚本不执行寻找界面按钮的滑屏手势；检查紧凑屏幕、大字体、键盘和文件选择流程。证据包含截图、UI XML、结果与日志。

演示签名保存在 Actions cache，源码不保存密钥；同一演示签名存续期间支持覆盖安装。正式渠道密钥通过持久备份及 GitHub Secrets 管理。

本版实际通过的运行、提交和截图见 [VALIDATION.md](VALIDATION.md)。实体控制板与现场加工结果独立记录。
