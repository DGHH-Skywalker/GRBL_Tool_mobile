# 0007：0.3 执行可靠性与完整演示

状态：实现。沿用 USBSerialForAndroid、SkiaSharp、Svg.Skia、Clipper2、Microsoft.Data.Sqlite 与现有 Cyotek 抽取，不新增运行时依赖。

## 启动事务

DeviceSession 在唯一串口所有者锁内捕获连接、控制器世代、就绪许可、管理操作修订和 WPos；在后台线程完成整文件解析、内容哈希、字节冻结。回到所有者锁后检查修订、坐标及新鲜 Idle，将启动命令与执行记录原子写入 SQLite，再发送第一批字节。界面确认的起点也参与验证。

G-code 分析支持显式 WorkPosition，绝对和相对移动均检查实际端点；首个坐标移动必须声明 G0/G1。每个 UI 输入变更递增准备修订，旧异步转换结果不能覆盖新输入，旧任务不能启动。

## 就绪许可

读取配置清除许可，完成身份/配置/模态读取后等待新状态，人工确认 Arm。控制器 Welcome、报警、门状态、命令错误、取消、任务故障、传输故障清除许可。未通过复位确认的任务故障先要求人工软件复位，然后重新读取配置并就绪。控制器返回 Welcome 后清空旧配置与坐标。活动任务的继续必须处于新鲜 Hold:0 并人工确认。

## 发送与持久化

已报告的 RX 容量启用 FIFO 字符窗口，窗口计数包含换行并保留一个字节，未知容量保留逐行模式。超出窗口的单行在启动前拒绝。ACK 只移除最早在途行；所有行确认后才能发送独立 G4 P0，之后主动查询并等待新的 Idle。

进度最多每秒落盘一次，状态变化、启动与终止立即落盘。历史记录包含任务名、哈希、参数、启动位置、区域、固件、开始/更新时间和确认/总行数。SQLite 使用向前兼容的加列迁移，已有文件仍可打开。

## 演示及呈现

DemoTransport 实现同一 IByteTransport，通过异步响应、有限 RX、16 项规划队列与独立时钟模拟执行；SimulationService 持有真实 DeviceSession。演示和 USB 共享所有应用层工作流，分别使用正确的 Android 前台服务类型，并在 UI 层禁止同时连接。

通知每秒刷新并携带当前 execution ID 的暂停操作；继续需回到页面确认。Partial wake lock 仅在活动执行期间持有。预览把 1024 个路径片段合成 Skia 路径块，按可见工作坐标范围剔除不可见块，替换作品时释放原生对象。

## 验证

GitHub Actions 执行协议与会话回归、实际 Skia 转换、APK 签名校验及 Android API 35 模拟器脚本。模拟器脚本覆盖安装、内置演示、预览、开始、暂停、继续、后台完成、历史和参数修改阻止旧任务启动。真机性能与控制板兼容性独立验收。
