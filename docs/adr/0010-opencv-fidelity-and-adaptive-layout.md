# 0010：OpenCV 分场景保真轮廓、实际空间排版与短动画

2026-11-14。用户提交照片和完整二维码，指出全局阈值/曲线简化导致细节丢失和二维码斜边；同时要求消除能同屏显示内容的分页并改善全局动画。

## 已调查的 GitHub 实现

- OpenCV / shimat/OpenCvSharp：成熟的 CLAHE、双边滤波、Canny、局部阈值及连通域实现。采用 OpenCV 4.13.0（fe38fc608f6acb8b68953438a62305d8318f4fcd）、OpenCvSharp 4.13.0.20260602（99b2313468074a2fc876e5a273659e9e2e34a6b2）。Apache-2.0。
- sdcb/opencvsharp-mini-runtime：采用其精简 extern 构建补丁，固定 9c4b7b52d17ae7764c28a2d21dc5bcf4de51e7bb；Linux 测试运行包 4.13.0.45。实际检查 Android NuGet 的两个 ABI 均为 4 KB LOAD 对齐，故 Android 使用 Actions 从固定源码重建，NDK 28.2.13676358、静态 C++、core/imgproc/imgcodecs 和 16 KB 链接参数。验证 ELF 架构、LOAD 对齐及 APK 中实际文件，保留缓存和上游许可证。
- LingDong-/linedraw：照片通过高斯/Canny 转线稿的参考；其逐八点采样和 Perlin 扰动会改变几何，本项目不引入这些风格化步骤。
- visioncortex/vtracer：多色分层、像素/多边形/样条路径及自适应聚类方案。适合作为彩色 SVG 功能参考；当前激光单通道采用 OpenCV 的照片边缘与精确图文区域两条链路。
- Clipper2 2.0.0：沿用已接入的成熟布尔库，新增像素行程矩形的精确并集。区域模式保持整数格点边界，不使用 Potrace 贝塞尔拟合或按毫米粗简化。
- ZXing.Net 0.16.11：只用于测试，生成完整高密度二维码并对填充还原的轮廓进行解码，核验载荷及像素 IoU。

## 处理链路

自动模式按灰度直方图熵选择照片或图文，用户可显式选择。照片：双边去噪、CLAHE 局部对比度、轻度高斯、梯度自适应 Canny；按完整连通分量去除噪点，保留主轮廓的短分支。图跟踪输出开放路径，简化误差最多 0.2 个处理像素，避免强制闭合和额外连线。

图文：OpenCV Otsu 或用户固定阈值；扫描文档可选 Gaussian 自适应阈值。行程矩形按相同行程纵向合并，再由 Clipper2 并集得到精确像素外边界与孔洞。只删除共线冗余，保留二维码直角、细小阶梯和模块间隔。图文模式保留全部非空像素模块；照片去噪只作用于照片连通分量。预览摘要显示实际采用的模式。输出五位小数 G1；每个独立路径使用 M5/G0/M4/G1/M5，继续完整预检。

处理预算保持 100 万采样；明确限制矩形、路径、顶点和任务大小，超限返回提示，不通过自动加大误差丢失细节。CsPotrace 留作兼容和回归比较；界面主轮廓改用 OpenCV 链路。

## 验收改进

NASA / scikit-image 的公有领域真实照片固定 URL 和 SHA256，由 CI 获取，输出原图、旧轮廓、新轮廓、边缘参考及覆盖率。完整高密度二维码分别使用 2、3、5 像素模块，要求所有区域边界保持轴向、还原 IoU≥0.995、ZXing 解码载荷一致。另测渐变照明下的单像素笔画。Android 实际导入这两类样本生成并保留截图。

本轮附图在会话中可见，未作为工作区可读文件提供。报告中的自动化结果明确使用上述公有领域照片和测试载荷二维码，不将合成样本等同于用户原图。

## 界面

删除设备 FormPager；工作区域、上限、串口集中一页，维护与诊断按钮集中一页。详情 TextView 使用真实宽度、字体和剩余高度进行原生 StaticLayout 排版；只有实际溢出的日志才显示翻页。历史容量按可用高度和真实卡片高度计算，内容同屏时隐藏页码与翻页控件。

页面、选项卡、面板及就地提示采用 160 ms 淡入/6 dp 位移；按钮使用原生 RippleDrawable。仅改变合成属性，保持路径缓存；快速切换取消旧动画，系统关闭动画时直接显示最终状态。模拟器开启动画并记录切换视频和帧统计，保留原有小屏、大字体及键盘检查。
